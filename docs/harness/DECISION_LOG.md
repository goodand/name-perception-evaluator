- 질문: "응답자의 설명을 규칙으로 거르는 것처럼 읽히는데, 응답자에게 주입되는 프롬프트를 규칙으로 걸러야 하는 것 아냐?" → 둘 다 필요. 프롬프트 거름은 측정 도구 오염 방지, 설명 거름이 측정
- 질문: "키워드가 모두 소거된 뒤에 전달되는 것 맞지? 틀리면 공유하지 말고 수정을 반복해야" → 그때까지는 경고만 하고 그대로 보냈음. `prompt_check.gate` 추가: 걸리면 보내지 않음 → 격리 모델이 고침 → 다시 검사, 최대 3회, 안 되면 멈춤
- 대상: 답변자·사람 관점·평가자·생성자 지시문(이름 자리는 제외: 후보 이름 자체는 검사 대상 아님), gpt 형식 꼬리는 이유 기록 후 허용
- 실측: "software repository … JSON" → 1회차 고침이 "프로그램 저장소 … 형식"(다시 걸림) → 2회차 통과. 고침 결과의 "프로젝트"를 사전에 추가

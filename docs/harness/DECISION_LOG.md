## 주체 정리(2026-11-06, 사용자 "주체가 어떤 것들이 있어", "코드는 재현성이 있으니 주체에서 무시", "kiwi가 재현성이 있냐", "검색자를 따로", "외부 에이전트는 cli나 json 출력")
- 기준: 재현되지 않는 것만 주체. 규칙 판정·사전 검사·겹침·조합(combine)·Kiwi는 장치
- 내부 주체 4: 검색자(설명문만 받고 표준어·고빈도 낱말+출처), 작명자, 첫눈 독자(후보 응답자), 대조 평가자(격리 평가자). 용어는 초안, 하네스로 검사 후 확정
- 외부 주체 2쌍: 사용 중(사용 에이전트·사용자), 개발 중(개발 에이전트·개발자). 사용자는 내부에 넣지 않는다
- 지시문 고치는 모델은 없앤다 → 틀 고정 + 외부 에이전트가 빈칸만 채움(scripts/prompt_slots.py, docs/harness/prompt_templates.json). 수정 프로토콜: 걸린 빈칸만 다시 채움, 다른 빈칸·틀 변경 거부, 이전에 걸린 값 재제출 거부, 최대 3회, 대체어는 주지 않음
- 조사: 끝 글자로 갈래 — 한글 → Kiwi, 영어·숫자 → Kiwi 쓰지 않음(조사 자리면 다시 채움, 조사 없는 자리에 둠). 숫자 읽기 규칙은 뺌(사용자: 용어에 숫자가 쓰일 일은 거의 없음)
- Kiwi 재현 확인: 90조합 × 200회 × 별도 프로세스 3회, 출력 90가지·해시 동일(kiwipiepy 0.24.0). 버전 고정 필요
- 내부 주체 지시문에는 형식 말(schema·JSON)을 넣지 않는다: 첫눈 독자·관점은 자유 서술, 작명자도 평문(하이픈 이름 + 한 줄). 출력 문법 제한·첫눈 독자 보기 제시는 쓰지 않음
- 외부 에이전트는 개발 쪽 편향이 강해 역할 부여(persona)가 잘 안 먹는다 → 역할 부여 대신 CLI·JSON 입출력으로 묶고 규칙으로 검사(예: 키워드 점검은 검색자가 낸 낱말 중 고르기만, 새 낱말 거부, 뺀 이유는 정해진 보기)
